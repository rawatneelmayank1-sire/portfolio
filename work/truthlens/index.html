TruthLens

A PDF question-answering assistant that fact-checks every sentence of its own answer.

Open the repositorySkip to the problem

Problem

RAG answers can still invent a number or a date. TruthLens checks itself and shows how much of each answer the document actually backs.

What it does

  • Answers questions about an uploaded PDF with citations to numbered passages.
  • Judges every answer sentence as supported, partial or unsupported against the passages.
  • Rewrites or deletes flagged sentences, at most twice, then verifies again.
  • Returns a trust score: the share of supported sentences.
  • Shows the first draft next to the final answer, coloured by verdict.

Architecture

Three Docker Compose services: a Streamlit UI, a FastAPI API and PostgreSQL 16 with pgvector. The LangGraph agent, retrieval and reranker all run inside the one API process.

How it works

  1. Ingest

    PDF split into 1,200-character chunks with page numbers, embedded with bge-small, stored in PostgreSQL with pgvector.

  2. Retrieve

    Top 20 by vector and top 20 by BM25, merged with Reciprocal Rank Fusion.

  3. Rerank

    A MiniLM cross-encoder keeps the best 5, plus the rest of the top hit's page.

  4. Generate

    The LLM answers only from numbered passages and cites them; no passages means a fixed refusal.

  5. Verify

    One judge call labels each sentence; Pydantic validates the verdicts, retrying bad JSON.

  6. Rewrite

    LangGraph keeps supported sentences, fixes or removes the rest, and stops after 2 rewrites.

Design decisions

  • Fixing flagged sentences beats regenerating: good sentences stay untouched between rounds.
  • Same-page expansion fixed a list split across chunks, taking false refusals from 1 to 0.
  • CI fails the build if retrieval hit@5 drops below 0.85 or MRR below 0.55.
