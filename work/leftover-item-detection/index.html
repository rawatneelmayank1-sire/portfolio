Leftover Item Detection

Real-time detection of items left behind in classrooms, with priority-sorted Telegram alerts to faculty.

Code not publicSkip to the problem

Problem

Items left behind in a classroom are easy to miss once a lecture ends. This project watches the room and tells faculty.

What it does

  • Detects objects in the classroom camera feed in real time with YOLOv5 and OpenCV.
  • Sends Telegram alerts to faculty when an item is left behind.
  • Sorts alerts into priority-based categories.

How it works

  1. Watch

    Frames from the classroom camera are read with OpenCV.

  2. Detect

    YOLOv5 finds objects in each frame.

  3. Alert

    Items left behind trigger a Telegram message to faculty, sorted by priority.
