Blood Group Detection

Tests whether a pretrained CNN can tell blood group from a fingerprint, with leak-proof evaluation.

Open the repositorySkip to the problem

Problem

There is no known biological link between fingerprints and blood group, so high accuracy usually means leakage. This pipeline is built to expose that.

What it does

  • Classifies a fingerprint image into one of 8 blood groups with per-class scores.
  • Keeps each person or duplicate file on one side of the train and test split.
  • Compares every score with chance, majority-class and image-statistics baselines.
  • Serves a Flask upload page with a clear not-a-diagnosis note.

Architecture

Training, evaluation and the Flask demo share one feature extractor. If no model is trained, the app answers 503 with the command to run instead of crashing.

How it works

  1. Scan

    Read one folder per blood group in a fixed class order, so labels cannot shift silently.

  2. Group

    Group images by person id from the filename, or by a hash of the file bytes.

  3. Split

    StratifiedGroupKFold keeps groups whole and every class in the test set, checked by an assert.

  4. Extract features

    A frozen EfficientNet-B0 turns each 224 x 224 image into 1,280 numbers.

  5. Classify

    StandardScaler and an RBF SVM with calibrated probabilities, saved as one scikit-learn pipeline.

  6. Evaluate

    Score the exact saved test files against all three baselines and write a report.

Design decisions

  • Replaced a leaky per-image random split with a grouped stratified split.
  • An image-statistics baseline exposes models that only learn capture artefacts.
  • One class-order source of truth after finding training used alphabetical folder order.
